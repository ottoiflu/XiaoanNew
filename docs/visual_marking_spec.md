# 2D 视觉标注规格 (Visual Marking Spec v2D)

## 1. 线框图升级 (draw_wireframe_visual)

### 标签映射
| YOLO 类别 | 中文标签 | 颜色 | 用途 |
|-----------|----------|------|------|
| Electric bike | 目标车 | 绿 (0,255,0) | 主判定对象 |
| Tactile paving | 盲道 | 红 (0,0,255) | medium 判定 |
| parking lane | 停车线 | 黄 (255,255,0) | position 判定 |
| Curb | 路缘 | 橙 (0,165,255) | position 降级基准 |

### 标注元素
1. **中文标签**：每个目标 bbox 上方画标签（白底+彩边框+黑色文字）
2. **Set-of-Mark 数字**：每个目标 bbox 左上角标①②③④（按 objects 顺序）
3. **2D 重叠高亮**：主车 mask ∩ 盲道 mask → 半透明红覆盖；主车 mask ∩ 停车线 mask → 半透明绿覆盖
4. **主车加粗**：目标车轮廓线宽 3，其他线宽 2

## 2. Prompt 规则 (看图判)
- medium："若图中目标车①与盲道②有红色半透明重叠区域，判 [不合规-盲道]。若②存在但无红色重叠，判 [合规]。"
- position："若目标车①与停车线③有绿色重叠，判 [合规]。若③存在但①在③外，判 [不合规-超界]。"
- 保留无参照降级、禁停介质优先、维度间优先级

## 3. 误判量化
每次 baseline 抽 20 张 medium=[不合规-盲道] 样本，人工判定"车真压盲道"vs"遮挡假象"比例。
